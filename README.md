# 대전 오늘의 진짜 정보판

ALEPH Studio T04 과제용 웹 정보판입니다. 비개인 공개 원천인 Open-Meteo에서 대전의 현재 기온을 조회해 `Asia/Seoul` 날짜별로 보존합니다.

## 실제 데이터

- 신호: 대전 현재 기온
- 단위: °C
- 출처: Open-Meteo 공개 API
- 화면 표시: 값, 단위, 출처, 출처 시각, 조회 시각, 기준 시간대
- 저장 규칙: 같은 `signal_id + record_date`는 한 행으로 갱신하고, 다른 KST 날짜는 새 행으로 저장합니다. 공개 심사에는 최근 두 날짜만 보존합니다.

## 실패 재생

과제의 공식 공개 fixture 계약 1.1.0에 맞춰 정상 D1-A/D1-B/D2, timeout, auth, rate_limit, offline, schema_error, recover-d2를 합성 재생합니다. 실패는 마지막 정상값을 지우지 않고 `stale` 상태와 다음 행동을 표시합니다. 합성 값은 실제 날짜 기록에 저장하지 않습니다.

## 개인정보와 비밀값

개인정보나 개인 기록은 저장하지 않습니다. Open-Meteo는 이 호출에 비밀키가 필요하지 않으며, 소스·브라우저 코드·네트워크 응답·배포 파일에 API 키를 넣지 않습니다.

## 확인 방법 초안

1. 위치: 첫 화면의 ‘대전은 지금’과 아래 ‘실제 날짜 기록’ 영역으로 갑니다.
2. 행동: ‘지금 조회하고 기록’을 누른 뒤, ‘정상 저장과 다섯 실패 재생’에서 실패 버튼과 ‘다시 시도·복구’를 누릅니다.
3. 통과 모습: 값·단위·출처·두 시각·Asia/Seoul이 보이고, 같은 날은 1행, 다음 실제 날짜에는 2행과 어제 대비 변화가 보입니다. 합성 복구는 `fresh / none`, 2행, 120 pt입니다.
4. 안 될 때 모습: 마지막 정상값이 유지된 채 `stale`과 timeout/auth/rate_limit/offline/schema_error 중 원인이 표시되고 다시 시도 행동이 보입니다.

## AI와 본인 판단 초안

- AI에게 맡긴 일: 요구사항 정리, 화면 구성, 코드 구현, 공식 fixture 연결과 동작 검증.
- 본인이 직접 판단한 일: 공개할 데이터의 종류와 지역, 화면 문구, 최종 제출 여부를 확인합니다.
- AI 제안을 따르지 않은 일: 현재 없음. 비밀키가 필요한 원천 대신 공개 API를 사용해 노출 위험을 없앴습니다.
